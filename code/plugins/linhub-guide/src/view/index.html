功能包是 LinHub 平台的扩展单元，每个功能包独立实现一个业务功能，可单独安装/升级/禁用/卸载，不影响平台核心。

功能包遵循 PSR-4 自动加载规范，使用 ThinkPHP8 开发，可以依赖平台提供的各类服务，也可以引入自己的依赖。
lgg-pkg-linhub-guide/ ├── src/ │ ├── Controller/ # 控制器（处理HTTP请求） │ ├── Service/ # 业务服务层 │ ├── Model/ # 数据模型（可选） │ ├── view/ # 模板视图 │ └── Package.php # 功能包入口（可选，生命周期钩子） ├── migrations/ # 数据库迁移（可选） ├── public/ # 静态资源（可选） ├── README.md # 功能包说明 ├── composer.json # Composer 依赖声明 ├── manifest.php # 功能包信息（必填） ├── menus.php # 菜单声明（可选） ├── permissions.php # 权限项声明（可选）
1. manifest.php（必填）

功能包基础信息声明，包含名称、版本、描述、依赖、权限/菜单入口等。

<?php return [ 'name' => 'lgg/linhub-guide', // 包名 'short' => 'linhub-guide', // 短标识（全局唯一） 'title' => '林枢演示功能包', // 显示名称 'version' => '0.1.0', // 版本号 'description' => '林枢演示功能包', // 描述 'dependencies'=> [], // 依赖其他功能包 'platform' => [ 'host' => '>=0.1.0', 'php' => '>=8.1', ], 'permissions' => 'permissions.php', // 权限声明文件 'menus' => 'menus.php', // 菜单声明文件 ];
2. menus.php（可选）

声明功能包的后台导航菜单，支持多级菜单，绑定权限。

<?php return [ [ 'id' => 'devtools', 'parent' => null, 'title' => '开发辅助', 'route' => null, 'icon' => 'el-icon-s-tools', 'order' => 900, 'perms' => [], ], [ 'id' => 'linhub-guide.index', 'parent' => 'devtools', 'title' => '功能包介绍', 'route' => 'linhub-guide.index', 'icon' => 'el-icon-document', 'order' => 10, 'perms' => [], ], ];
3. permissions.php（可选）

声明功能包的权限项，用于超管给角色分配权限。格式：分组 => 权限列表。

<?php return [ 'linhub-guide' => [ [ 'name' => '功能包介绍', 'perm' => 'linhub-guide:index', 'description' => '访问功能包介绍页面' ] ] ];
4. Package.php（可选，生命周期钩子）

功能包入口类，提供三个可选钩子：

  • install() - 安装后执行
  • upgrade(string $fromVersion) - 升级后执行，参数为旧版本号
  • rollback() - 回退后执行
开发阶段

开发者在本地开发功能包，压缩打包后上传到 LinHub 暂存区，等待审核。

审核阶段

超管审核功能包，通过后自动安装到系统，不通过则留在暂存区等待修改重提。

运行阶段
  • 启用/禁用：超管可以随时禁用功能包，禁用后代码自动移入隔离区，不加载、不可访问。
  • 升级：上传新版本到暂存区，审核通过后自动升级，升级前自动备份当前版本。
  • 回退：如果新版本有问题，可以回退到任意历史备份版本，最多展示最近10个版本。
  • 卸载：卸载后移除代码和数据（数据可选择保留）。

LinHub 使用「权限项 → 角色 → 用户」三级权限体系：

  1. 功能包在 permissions.php 声明自己需要管控的权限项
  2. 超管在「权限组管理」给角色分配权限
  3. 用户登录后，界面根据权限自动显示/隐藏对应功能
  4. 后端接口也会做权限校验，未授权无法访问

功能包可以依赖平台提供的公共服务，在 manifest.php 的 services.requires 声明：

'services' => [ 'provides' => [], 'requires' => ['logging', 'config'], ]

常用平台服务：

  • logging：日志服务
  • config：配置服务
  • auth：登录用户信息
  • datadict：数据字典服务
  • attachment：附件托管服务
  • message：站内消息服务

LinHub 后台使用 Vue3 + Element Plus + workdesktop-ai 组件库开发，功能包前端视图继承此技术栈：

  • 使用 ThinkPHP 原生 fetch() 渲染模板
  • 页面在后端已经引入 Vue、Element Plus、workdesktop-ai 的 CDN 资源，无需重复引入
  • 表格使用 wd-data-grid，表单使用 wd-form，面板使用 wd-panel，弹窗抽屉使用 workdesktop 提供的组件
